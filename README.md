# Hugo Alcolea — Portfolio

Portfolio personal en castellano, catalán e inglés. HTML, CSS y JavaScript sin dependencias de compilación.

## Desarrollo local

Desde la raíz, ejecuta `python3 -m http.server 8000` y abre http://localhost:8000.

## Publicación en Vercel

Importa este repositorio. Framework: **Other**. No necesita instalación ni comando de build. La raíz del repositorio es el directorio de publicación.

## Edición

- `index.html`: contenido base en castellano y estructura.
- `app.js`: traducciones, selector de idioma y mensaje de WhatsApp.
- `style.css`: diseño y estilos responsive.
- `assets/`: imágenes optimizadas de los proyectos enlazados (no capturas exactas de sus interfaces).
